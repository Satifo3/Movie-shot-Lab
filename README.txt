Movie shot Lab - private animation cinematography quick reference

使い方
1. index.html をブラウザで開く
2. 「用語早見」から項目をタップ → 該当ページへ移動
3. 作例がある項目は「作例GIF」タブで実際のアニメ作例を確認
4. ☆ でお気に入り登録（ブラウザ内に保存）
5. 「最近見た項目」から直前の項目へすぐ戻れる
6. 画面下の「目次に戻る」でいつでもホームへ

仕様
- マニュアル47ページ：ローカル表示（オフライン可）
- 作例GIF：公開元のHatena CDNからオンライン表示
- 作例出典：https://usapen3.hatenablog.com/entry/2016/12/18/234110
- GIFはアプリ内へ複製せず、公開元URLを参照する方式
- iPhone / PC 対応

注意
- 個人用の早見ツールとして利用してください。
- 作例GIFの表示にはインターネット接続が必要です。
